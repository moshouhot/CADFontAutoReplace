# v9.2.2 Selective Backport Review Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以可复现证据判断本地 `10.2.1` 是否应选择性吸收上游 `v9.2.2` 在运行时稳定性、AWS 对话框抑制、UI 与数据绑定方面的改动，并在不破坏绿色部署、JSON CLI、2013–2027 支持和合并 DLL 架构的前提下给出回移清单。

**Architecture:** 不直接 merge/cherry-pick `v9.2.2`。先把上游变更拆成三个独立审计包，每个包依次完成“语义差分、最小移植、自动验证、真实 CAD 验证、保留/撤销决策”；最终仅合并通过门禁的补丁。

**Tech Stack:** C#、WPF、MSBuild/.NET SDK 10.0.201、AutoCAD .NET API、原生 inline hook、Windows 注册表、PowerShell、Git。

## Global Constraints

- 保留本地 4 个合并 DLL：`AFR-ACAD2013-2017.dll`、`AFR-ACAD2018-2024.dll`、`AFR-ACAD2025-2026.dll`、`AFR-ACAD2027.dll`。
- 保留 `RuntimeAutoCadPlatform`、绿色目录、`AFR.config.json`、`DeployerCli`、`AFRSELFTEST` 和 AutoCAD 2013–2027 支持。
- 上游比较基准固定为 tag `v9.2.2`（`5b259d8069ffa73e0fc25da810aadb9960963134`），本地基准固定为 `4ad172f4d5eeb7835b29a4994ff3c99750d99f7d`。
- 禁止整文件覆盖本地 `AppInitializer.cs`、`AfrCommands.cs`、`MainViewModel.cs`、`NativeFontHookProfile.cs`。
- 每个审计包单独提交；任一包可独立撤销。
- 实机验证至少覆盖 AutoCAD 2017、2018、2024、2025、2026、2027；没有对应环境时不得宣称该版本验证通过。

---

## Preliminary Decision

| 审计包 | 主要不同 | 初步价值 | 初步结论 |
|---|---|---:|---|
| 运行时稳定性 | 上游改为静态 CAD 命令、强化 `NativeInlineHook`、初始化/卸载幂等性、日志上下文与资源释放 | 高 | **值得更新，但必须选择性回移** |
| AWS 对话框抑制 | 上游新增抑制状态识别、所有权标记、安装/升级覆盖和安全清理 | 高 | **最值得优先更新** |
| UI 与数据绑定 | 上游精简 ViewModel/`UiCommand`、修正绑定生命周期，并新增 About 窗口 | 中 | **绑定修复值得更新；About 窗口可选** |
